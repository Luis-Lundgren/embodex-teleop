# Security Policy

## Reporting Security Vulnerabilities

We take the security of Embodex seriously. If you discover a potential vulnerability in this repository, please do **NOT** open a public issue.

Instead, please report security vulnerabilities directly to the maintainers:

- **Security Contact:** Luis Lundgren
- **Email:** `lundgrenluis@gmail.com`

Please include as much detail as possible in your report:
- The affected component or endpoint.
- Steps to reproduce the vulnerability or a minimal Proof of Concept (PoC).
- Potential impact and severity.

## Response Process

- We will acknowledge receipt of your report within 48 hours.
- We will coordinate a fix and release an advisory or update in a timely manner.
- Credit will be given to the reporter if desired.
